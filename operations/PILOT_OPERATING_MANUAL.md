# Pilot Operating Manual

Purpose: run the first 25-file ApprovalPath OS pilot without pretending the company is already a lender, broker, credit repair company, or legal advisor.

## Pilot Promise

For each declined, delayed, or difficult buyer file, ApprovalPath OS will return:

- primary approval obstacle
- secondary approval obstacle
- approval obstacle score
- fundability status
- assigned approval path
- missing document list
- 30/60/90 day action plan
- possible lender, agency, DPA, or program direction

ApprovalPath OS will not promise approval, quote loan terms, alter documents, or route borrower information without consent.

## File Review SLA

| Stage | Target Time |
|---|---:|
| Intake acknowledgment | same business day |
| Consent requested | same business day |
| Initial diagnosis after complete intake | 24 hours |
| Missing document list | 24 hours |
| Approval path assignment | 48 hours |
| Partner/lender routing package | 72 hours after consent and documents |

## Daily Workflow

1. Review new intakes.
2. Confirm consent status.
3. Assign the file stage in the app.
4. Score credit, capacity, capital, collateral, documentation, and compliance.
5. Assign one primary approval path.
6. Complete required task and document checklists.
7. Add file notes after every call, review, or partner response.
8. Move files to Lender Match Ready only after consent and minimum documents are present.
9. Export CSV weekly for pilot reporting.

## Escalation Rules

Pause the file and escalate before routing if any of these appear:

- suspicious or altered documents
- source of funds cannot be explained
- borrower asks for false document help
- occupancy story is inconsistent
- borrower does not authorize sharing
- compensation or referral request seems tied to a settlement-service referral
- staff would need to take an application or negotiate terms without proper licensing

## Weekly Pilot Review

Every week, review:

- files received
- files classified
- files missing consent
- files missing documents
- path distribution
- average obstacle score
- lender-ready files
- approved files
- paused files
- partner source quality
- common missing documents
- partner/lender response quality
