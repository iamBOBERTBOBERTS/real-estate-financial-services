# ApprovalPath OS Simple User Guide

This guide is for people who do not want technical instructions.

## What This Tool Does

ApprovalPath OS helps you keep track of buyers who are hard to approve for a mortgage.

Use it to:

- add buyers
- upload lead lists
- see what is blocking approval
- collect missing documents
- write the next step
- see which lender type may fit
- track permission before sharing files
- prepare a partner packet
- track handoffs and outcomes
- switch demo roles
- control consent and partner visibility
- export or import a backup
- review audit logs as an admin
- download a report

## The 5 Main Buttons

### Home

Shows all buyer files and the next step for each buyer.

### Add Many Leads

Use this when you have a spreadsheet or file full of leads.

Steps:

1. Click **Choose Lead Files**.
2. Pick your CSV or JSON file.
3. Click **Check the Leads**.
4. Review the preview.
5. Click **Add These Leads**.

### Add One Buyer

Use this when you only need to add one buyer.

This screen now includes the **Impossible File Scan**.

Fill in what you know about:

- why the buyer was denied or stalled
- credit score range
- income
- debt
- cash available
- timeline
- documents already collected
- safety concerns

The tool will create a rescue tier:

- **Rescue Now**: possible short-term path
- **Approval Sprint**: needs 30-120 days of focused work
- **Rebuild First**: needs a longer prep plan
- **Protect & Refer**: do not push to lender yet; route to safer help first

### Work Files

Use this every day.

Use the **Work View** menu to find the exact files that need attention.

Helpful views include:

- Ready to Send
- Sent - Needs Follow-Up
- More Info Requested
- Outcome Needed
- Approval Sprint
- Rebuild First
- Protect & Refer
- Won / Closed
- Lost / Not Ready

Each row shows the buyer, rescue tier, blocker, lender lane, handoff status, outcome, follow-up date, and next action.

Use the quick buttons to open the review screen, update an outcome, set a follow-up, or prepare a partner packet.

### Find Lenders

Use this to see what lender lane may fit the buyer problem.

Examples:

- cash shortage means down payment assistance
- high debt ratio may need manual review or debt strategy
- self-employed income may need bank statement or non-QM options
- property issues may need a specialty lender

### Review Buyer

Use this to see the **Hard-File Review**.

It shows:

- rescue tier
- primary blocker
- secondary blockers
- buyer timeline
- cash available
- credit range
- income type
- down payment help needed
- lender-ready status
- recommended next move

You can also update the scan here.

Use **Edit Scan Answers** when:

- the buyer gives updated income
- the buyer pays off debt
- more documents are collected
- cash available changes
- a lender gives a new denial reason
- a protection flag needs to be added or removed

Click **Save and Recalculate** to update the rescue tier, blockers, checklist, and lender route.

The **Lender Match** box shows the best lender lane to try next. This is not an approval. It is a routing suggestion.

## Partner Packets

On **Review Buyer**, use:

- **Export Partner Packet**
- **Copy Packet Text**
- **Print Packet**

Before the packet is prepared, the tool asks you to confirm:

- the buyer gave permission
- the packet does not include SSN, full credit reports, bank account numbers, or sensitive IDs
- you are not promising approval
- licensed mortgage professionals handle loan terms and formal eligibility

The packet includes the buyer summary, consent status, Impossible File Scan, financial snapshot, lender routing, documents, tasks, and compliance reminder.

## Handoff and Outcome Tracking

On **Review Buyer**, use **Handoff Status** to track where the file was sent.

Examples:

- Ready to send
- Sent to lender
- Sent to DPA partner
- Sent to housing counselor
- In review
- More info requested
- Paused
- Closed / completed

Use **Outcome Tracking** after a lender, counselor, realtor, builder, or buyer gives feedback.

The **Learning Snapshot** shows simple lessons from the file so the team can learn which lender lane or partner worked best.

## Permissions, Roles, and Backups

Use the **Demo Role** menu at the top to see how the tool behaves for different users.

Roles include:

- Owner
- Admin
- File Analyst
- Partner
- Lender
- Counselor
- Read Only

Outside roles only see files that were explicitly shared in **Partner Visibility**.

On **Permissions**, use **Structured Consent** before exporting packets or marking a file sent to a lender, counselor, realtor, or builder.

Use **Export Backup** to save a JSON backup. Treat backup files as sensitive and store them carefully.

Restore accepts complete version 1 JSON backups up to 4 MB. The app checks every collection before changing local data; if a browser storage write fails, the previous local data is restored.

Use **Audit Logs** as Owner or Admin to review major actions like consent changes, packet exports, handoffs, outcomes, imports, and backups.

## Important Safety Rules

- Do not promise approval.
- Do not call the rescue tier an approval.
- Do not change documents.
- Do not share a buyer file until permission is signed.
- Do not promise a lender decision before the lender gives one.
- Use the tool to organize the file and choose the best next route.

## Weekly Routine

Every week:

1. Add new leads.
2. Open **Work Files**.
3. Check every file with a missing next step.
4. Mark files ready for lender review only when permission and documents are ready.
5. Click **Download Report** on the Home screen.

## If Something Looks Wrong

Click **Reset Demo Data** only if you want to return the sample buyers. Do not click it if you are working with real buyer files.
