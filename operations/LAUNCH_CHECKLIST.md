# Launch Checklist

## Legal and Compliance

- Confirm launch state or states.
- Review whether any activity triggers mortgage broker or MLO licensing.
- Review compensation model for RESPA Section 8 risk.
- Review privacy policy, consent language, data-sharing authorization, and referral disclosure.
- Review whether any credit-related services trigger state or federal credit services rules.
- Create document retention policy.
- Create incident response process for borrower data.
- Create vendor due diligence checklist for software and referral partners.

## Operations

- Set up borrower intake form.
- Set up consent capture.
- Set up secure document collection.
- Set up borrower file workspace.
- Set up partner submission process.
- Set up communication log.
- Set up outcome tracking.
- Set file review SLA.
- Set escalation rules for fraud, legal, or licensing concerns.

## Partner Network

- Identify FHA manual underwriting partners.
- Identify VA-focused partners.
- Identify USDA partners.
- Identify DPA-friendly lenders.
- Identify local housing counseling agencies.
- Identify credit unions and community banks.
- Identify portfolio and non-QM lenders.
- Identify bank statement and self-employed borrower lenders.
- Identify manufactured home lenders if relevant.
- Score each partner by product appetite, turn time, communication quality, and outcome history.

## Sales Pilot

- Recruit 5 realtors or one builder sales team.
- Offer first 25 file reviews as a pilot.
- Track every file by source partner.
- Deliver a weekly partner report.
- Capture before/after approval path outcomes.
- Ask partners what would make the service worth paying for monthly.

## Product

- Use the MVP command center in `app/index.html`.
- Enter every pilot borrower into the dashboard.
- Assign path type and score.
- Add next action and owner.
- Track consent status.
- Track lender/program path.
- Log the outcome.
