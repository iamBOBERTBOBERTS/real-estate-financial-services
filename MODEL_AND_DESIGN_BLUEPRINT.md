# Model and Design Blueprint

Working brand: **ApprovalPath OS**

Operating concept: **The Impossible Approval Desk**

Last updated: 2026-05-29

## 1. The Business We Are Building

ApprovalPath OS is a mortgage approval engineering company for homebuyers who are hard to approve.

The company does not start by trying to be another lender. It starts as the specialist layer that diagnoses difficult files, rebuilds borrower readiness, matches the borrower to the right path, and routes the file to capable lenders, agencies, or programs.

The market position is simple:

**Denied is not final. Difficult is our specialty.**

The business exists for buyers who were told:

- Their credit is too low.
- Their debt-to-income ratio is too high.
- They do not have enough cash to close.
- Their income cannot be used.
- Their self-employment file is too messy.
- Their file needs manual underwriting.
- Their property does not fit the lender box.
- They should come back later.

ApprovalPath OS turns that dead end into a structured rescue path.

## 2. Category Design

Do not call this a lead generation company. That makes the business feel cheap, replaceable, and compliance-risky.

Own a sharper category:

**Mortgage Approval Engineering**

Supporting language:

- A second-opinion desk for difficult mortgage files.
- A rescue system for hard-to-approve homebuyers.
- A lender-routing and file-rebuild platform for declined buyers.
- A homebuyer approval lab for complex borrower profiles.

The category should feel more like underwriting intelligence than marketing.

## 3. The Core Offer

### Consumer Offer

**Impossible Approval Review**

A structured review for homebuyers who were declined, delayed, or told they are not ready.

Deliverables:

- Denial reason diagnosis
- Approval obstacle score
- Missing-document checklist
- Cash-to-close strategy
- DPA and grant screening
- Income usability review
- Credit and derogatory-event triage
- Lender/program path recommendation
- 30, 60, or 90 day action plan

### Realtor Offer

**Buyer Save Desk**

A rescue desk for agents whose buyers fall out of escrow, fail preapproval, or cannot get clean financing.

Deliverables:

- Buyer rescue intake
- File status updates
- Requalification path
- Deal probability rating
- Escalation to lender partners
- Re-engagement reminders
- Monthly pipeline recovery report

### Builder Offer

**Fallout Recovery Desk**

A financing recovery system for builders losing buyers to credit, DTI, down payment, or documentation problems.

Deliverables:

- Buyer fallout classification
- Recovery timeline estimate
- DPA and incentive stacking review
- Preferred lender routing
- Recovered buyer pipeline tracking
- Builder sales team dashboard

### Lender Partner Offer

**Difficult File Routing Network**

A curated network that sends lenders files matching their true lending appetite.

Deliverables:

- Borrower profile pre-classification
- Document readiness score
- Program-fit tagging
- Consent-based referral package
- Outcome feedback loop

Important: compensation must be reviewed carefully so it does not become an illegal referral-fee or kickback structure.

## 4. The Approval Engine

Every borrower should be classified across five dimensions.

### A. Credit

Signals:

- Middle score
- Thin file
- Payment history
- Collections
- Charge-offs
- Judgments or liens
- Bankruptcy, foreclosure, short sale, or deed-in-lieu timing
- Credit utilization

Outputs:

- Credit-ready now
- Credit-ready with documentation
- Credit-ready with debt movement
- Credit-rebuild required
- Currently ineligible

### B. Capacity

Signals:

- DTI ratio
- Residual income
- Housing payment shock
- Installment debt
- Revolving debt
- Student loan treatment
- Co-borrower or non-occupant co-borrower options

Outputs:

- AUS likely
- Manual underwrite candidate
- Debt-payoff path
- Income-add path
- Lower purchase price needed

### C. Capital

Signals:

- Down payment available
- Closing cost gap
- Reserves
- Gift fund options
- Seller credit opportunity
- Lender credit opportunity
- DPA eligibility

Outputs:

- Cash sufficient
- DPA path
- Seller-credit path
- Gift/reserve path
- Savings timeline required

### D. Collateral

Signals:

- Property type
- Occupancy
- Condition
- Appraisal risk
- Manufactured home issues
- Condo/project issues
- Repair requirements

Outputs:

- Standard property path
- Repair/path exception needed
- Specific lender/product required
- Property not viable for current path

### E. Character and Compliance

Signals:

- Documentation consistency
- Fraud risk
- Identity verification
- Occupancy consistency
- Source of funds clarity
- Borrower communication reliability

Outputs:

- Clean file
- Needs explanation letters
- Needs source documentation
- Do not proceed without legal/compliance review

## 5. Borrower Path Types

Each file should land in one primary path and one optional secondary path.

| Path | Buyer Profile | Main Strategy |
|---|---|---|
| DPA Stack Path | Cash-short buyer | Match grants, assistance, seller credits, lender credits, and eligible loan programs |
| Manual Underwrite Path | AUS denial but human story makes sense | Build compensating factors, reserves, rental history, explanation letters, and documentation |
| Income Rescue Path | Self-employed, 1099, gig, variable income | Determine usable income, missing docs, alternative products, or seasoning timeline |
| Credit Comeback Path | Low score or derogatory history | Lawful credit triage, documentation, timing rules, and re-score planning through qualified partners |
| Debt Strategy Path | High DTI | Payoff sequencing, restructure strategy, co-borrower options, lower price path |
| Alternative Product Path | Bank statement, non-QM, portfolio, asset-based | Match the borrower to lenders who actually want the profile |
| Property Rescue Path | Collateral problem | Identify product/property mismatch and viable lender or property solution |
| Pause and Build Path | Not approvable today | Give a specific 30, 60, 90, or 180 day path instead of vague encouragement |

## 6. Revenue Model

Start with revenue that is clean, understandable, and less dependent on settlement-service referral fees.

### Phase 1: Consumer-Paid Diagnostic

Product:

- Free eligibility triage
- Paid Impossible Approval Review
- Optional monthly requalification support

Potential pricing:

- Basic triage: free
- Full file review: $149 to $499
- Active rescue support: $49 to $199/month

Notes:

- Fees should pay for analysis, planning, education, and file organization.
- Avoid charging for promises of approval.
- Avoid representing that the fee buys loan approval.

### Phase 2: Realtor and Builder Subscription

Product:

- Buyer Save Desk for agents
- Fallout Recovery Desk for builders

Potential pricing:

- Solo agent: $99 to $299/month
- Team/brokerage: $499 to $2,500/month
- Builder sales office: $1,500 to $7,500/month

Notes:

- Charge for software, workflow, reporting, and administrative services.
- Do not structure payment as compensation for settlement-service referrals without legal review.

### Phase 3: Licensed Mortgage / Broker Layer

Once proven, decide whether to become licensed or partner with licensed entities.

Options:

- Stay a non-lender approval engineering platform.
- Become a licensed mortgage broker in target states.
- Build a joint venture only after serious RESPA review.
- Hire or partner with licensed MLOs.

This phase should wait until the operating system proves demand and the compliance model is reviewed.

## 7. Compliance Design

This business touches mortgage, consumer finance, personal data, referrals, and possibly credit-related services. It must be designed with compliance from day one.

Guardrails:

- No approval guarantees.
- No false documents.
- No borrower steering based on hidden compensation.
- No illegal referral fees or kickbacks.
- No taking applications or negotiating loan terms unless properly licensed.
- No credit repair promises unless operating under lawful credit service rules.
- Written consent before file sharing.
- Clear privacy policy and data handling procedures.
- Secure storage for borrower documents and nonpublic personal information.

Official source anchors:

- CFPB RESPA FAQ: RESPA Section 8 prohibits referral-fee and unearned-fee arrangements in federally related mortgage transactions. Source: https://www.consumerfinance.gov/compliance/compliance-resources/mortgage-resources/real-estate-settlement-procedures-act/real-estate-settlement-procedures-act-faqs/
- CFPB Loan Origination Rule: loan originator compensation, qualification, registration, and related mortgage origination rules live under Regulation Z/TILA guidance. Source: https://www.consumerfinance.gov/compliance/compliance-resources/mortgage-resources/loan-origination-rule/
- FTC Safeguards Rule: covered financial institutions must maintain safeguards for customer information. Source: https://www.ftc.gov/business-guidance/resources/ftc-safeguards-rule-what-your-business-needs-know
- NMLS SAFE Act materials: mortgage loan originator activity and licensing must be checked against state and federal requirements. Source: https://mortgage.nationwidelicensingsystem.org/SAFE/NMLS%20Document%20Library/MLO-Requirements-SAFE.pdf

This is not legal advice. Before launch, a mortgage compliance attorney should review the exact services, intake language, compensation model, lender relationships, state licensing exposure, and privacy/security controls.

## 8. Brand Design

The brand should feel:

- Serious
- Precise
- Relentless
- Human
- Calm under pressure
- Built for complicated files

Avoid:

- Flashy credit repair vibes
- Guaranteed approval language
- Predatory rescue language

Use a professional underwriting-lab feel:

- Dark ink, white, cool gray, controlled green, and amber highlights
- Clean dashboards
- Evidence-first layouts
- Document and checklist motifs
- Status tags and progress states
- Simple confidence indicators

- “We find the path your first lender missed.”

- “Guaranteed approval”
- “Secret lender loopholes”
- “Erase your credit”
- “Everyone qualifies”
- “No documentation needed”

## 11. Scoring System

Use a simple 0 to 100 score for internal sorting.

### Approval Obstacle Score

Higher means harder.

- Credit: 0 to 20
- Capacity/DTI: 0 to 20
- Capital/cash-to-close: 0 to 20
- Collateral/property: 0 to 15
- Documentation complexity: 0 to 15
- Compliance/fraud risk: 0 to 10

Bands:

- 0 to 25: Easy save
- 26 to 50: Workable with routing
- 51 to 70: Rescue plan needed
- 71 to 85: Long path
- 86 to 100: Pause or decline

### Fundability Status

Use plain statuses:

- Fundable Now
- Fundable With Conditions
- Fundable With Different Lender
- Build Plan Required
- Not Currently Viable

## 14. Go-To-Market Model

### Beachhead

Start with realtors and builders who already lose deals because buyers cannot get financing.

Best early customers:

- Agents serving first-time buyers
- Agents serving lower-to-middle income buyers
- New construction sales teams
- Manufactured home dealers/builders
- Investor-friendly agents with self-employed buyers
- Teams that generate lots of buyer leads but lose them after preapproval

### First Campaign

Campaign theme:

**Stop throwing away declined buyers.**

Offer:

**Send us the declined file. We will tell you whether the buyer is fundable now, fundable with a different path, or needs a build plan.**

### Lead Magnets

- Denied Buyer Rescue Checklist
- DPA Stacking Map
- Self-Employed Mortgage Readiness Review
- High-DTI Buyer Save Guide
- Manual Underwrite Readiness Scorecard

## 15. 90-Day Launch Roadmap

### Days 1-15: Foundation

- Finalize brand name and disclaimers.
- Build intake form.
- Build borrower file template.
- Build denial reason taxonomy.
- Build first lender/program matrix.
- Identify 10 to 20 lender/agency partners.
- Draft privacy, consent, and referral disclosures for legal review.

### Days 16-30: Manual Pilot

- Recruit 5 to 10 realtors or one builder team.
- Review 25 declined or stuck buyer files.
- Track obstacle patterns.
- Track recommended paths.
- Track lender response and outcomes.
- Refine scoring.

### Days 31-60: Operating System MVP

- Build Command Center.
- Build borrower intake.
- Build file diagnosis screen.
- Build approval plan generator.
- Build partner status view.
- Add consent tracking.
- Add outcome tracking.

### Days 61-90: Growth Loop

- Publish partner-facing offer.
- Launch monthly partner reports.
- Build case-study library without exposing private borrower data.
- Create lender appetite database.
- Add automated reminders.
- Add conversion analytics by borrower type.

## 17. The Strategic Moat

The moat is not a website. It is data.

Over time, ApprovalPath OS learns:

- Which borrower profiles fail where
- Which lenders actually approve difficult cases
- Which DPA programs work in practice
- Which document gaps kill files
- Which partners send quality cases
- Which rescue paths produce approvals

That feedback loop becomes the business.

The endgame is a proprietary difficult-file intelligence system that routes complex borrowers better than any single lender, agent, or builder can on their own.
